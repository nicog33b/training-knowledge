# Catálogo del curso Frontend Developer · Semi Senior [frontend-semi-senior]
El salto a semi senior: TypeScript, el modelo mental de React, estado y datos del servidor, testing, herramientas de build, rendimiento (Core Web Vitals) y seguridad web.
Subtemas (id: título — resumen). Pide uno con leer_subtema solo si la pregunta lo necesita.
- typescript-practico (1 · TypeScript y el modelo mental de React): TypeScript práctico — Tipos que aportan: inferencia, uniones y estrechamiento, genéricos, tipos de utilidad, unknown frente a any y validar en el borde (zod).
- react-modelo-mental (1 · TypeScript y el modelo mental de React): El modelo mental de React — UI = f(estado): renderizado, props y estado, inmutabilidad, keys en listas y qué provoca un re-render.
- efectos-y-sincronizacion (1 · TypeScript y el modelo mental de React): Efectos: sincronizar con el exterior — useEffect sirve para sincronizar con sistemas externos, no para derivar datos; dependencias, limpieza y cuándo no necesitas un efecto.
- estado-y-datos-del-servidor (2 · Datos, estado y calidad): Estado de la UI y datos del servidor — Distinguir estado local, compartido y datos del servidor; caché, revalidación, estados de carga y por qué no meterlo todo en un store global.
- testing-frontend (2 · Datos, estado y calidad): Testing en frontend — Probar comportamiento como lo usa una persona (Testing Library), qué cubrir con unitarios, integración y extremo a extremo, y tests que no se rompen al refactorizar.
- build-y-bundling (2 · Datos, estado y calidad): Build, bundling y módulos — Qué hace el bundler (Vite, esbuild, Rollup): módulos ES, tree shaking, code splitting, carga diferida y medir el peso del bundle.
- core-web-vitals (3 · Rendimiento, seguridad y accesibilidad avanzada): Core Web Vitals: LCP, INP y CLS — Las tres métricas de experiencia (umbrales en el percentil 75), qué las causa y cómo mejorarlas; INP sustituyó a FID en 2024.
- seguridad-web (3 · Rendimiento, seguridad y accesibilidad avanzada): Seguridad web para frontend — XSS y cómo lo evitan los frameworks, CSP, CSRF y cookies SameSite, CORS, dónde guardar tokens y dependencias vulnerables.
- accesibilidad-avanzada (3 · Rendimiento, seguridad y accesibilidad avanzada): Accesibilidad avanzada: ARIA y foco — Patrones accesibles (diálogo, menú, pestañas), gestión del foco en SPA, regiones live y probar con lectores de pantalla.
