# Catálogo del curso Frontend Developer · Junior [frontend-junior]
Lo que un frontend junior debe dominar para trabajar en un equipo: HTML semántico, CSS de maquetación, JavaScript del navegador, asincronía, HTTP, Git y accesibilidad básica.
Subtemas (id: título — resumen). Pide uno con leer_subtema solo si la pregunta lo necesita.
- html-semantico (1 · HTML y CSS que aguantan): HTML semántico — Elegir el elemento por su significado (header, nav, main, button, label…): accesibilidad, SEO y comportamiento gratis del navegador.
- cascada-y-especificidad (1 · HTML y CSS que aguantan): La cascada, la especificidad y el box model — Por qué un estilo gana a otro (origen, especificidad, orden), herencia, box-sizing y cómo evitar guerras de !important.
- flexbox-y-grid (1 · HTML y CSS que aguantan): Maquetación con Flexbox y Grid — Flexbox para una dimensión, Grid para dos; alinear, repartir espacio y plantillas sin hacks.
- responsive (1 · HTML y CSS que aguantan): Diseño responsive — Mobile first, viewport, unidades relativas, media queries y container queries, imágenes adaptables.
- javascript-esencial (2 · JavaScript del navegador): JavaScript esencial: valores, ámbito y closures — Tipos y comparación, let/const, ámbito de bloque, funciones como valores, closures y referencias frente a copias.
- dom-y-eventos (2 · JavaScript del navegador): DOM y eventos — Seleccionar y modificar el DOM, escuchar eventos, propagación y delegación, y no bloquear el hilo principal.
- asincronia-y-event-loop (2 · JavaScript del navegador): Asincronía: event loop, promesas y async/await — Cómo JavaScript hace varias cosas con un solo hilo: pila, cola de tareas y microtareas; promesas, async/await y manejo de errores.
- http-y-fetch (2 · JavaScript del navegador): HTTP y fetch — Métodos, códigos de estado, cabeceras y JSON; consumir una API con fetch, manejar errores, estados de carga y CORS a nivel básico.
- git-y-colaboracion (3 · El oficio en equipo): Git y colaboración — Commits pequeños con buenos mensajes, ramas, pull requests, resolver conflictos y revisar código de otros.
- accesibilidad-basica (3 · El oficio en equipo): Accesibilidad básica (WCAG 2.2) — Teclado, foco visible, textos alternativos, contraste, formularios con label y probar con lector de pantalla: lo mínimo que todo junior debe cumplir.
